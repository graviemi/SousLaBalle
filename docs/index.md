# Accueil

Bienvenue sur le site de l'association Sous La Balle.

Sous La Balle est une association loi 1901 destinée à promouvoir la pratique des jeux sportifs en salle sur le Plateau des Petites-Roches.

Nous seront heureux de vous accueillir pour jouer au volleyball ou au basket dans une ambiance détendue. Pour une pratique amateur ou tous les niveaux sont accéptés sans obligation de performances.
